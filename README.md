# Unfitted space-time DG methods: Lean formalisation and numerical experiments

Supplementary material for the paper

> F. Heimann, C. Lehrenfeld: *Higher Order Unfitted Discontinuous Galerkin Methods in Space
> and Time.*

|---|---|

| [`num_exp/`](num_exp/) | Scripts and data behind the figures and tables of the numerical examples, see [`num_exp/README.md`](num_exp/README.md). |
